## Convention de versionning

Pattern observé :
1. **Itération libre** sur `vN` (incrémentation) — chaque variante est figée une fois validée
2. **Une fois la "bonne" trouvée** : la version sans suffixe (ex: `caribbean`) devient l'alias canonique, parfois via `export { default } from '../caribbean-v15/page'`
3. Les anciennes versions **restent accessibles** pour comparaison interne
